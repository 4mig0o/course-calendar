课表转日历工具｜电脑小白使用说明

一、只在自己的电脑上使用

1. 把整个项目文件夹解压到电脑上。不要只拿出 index.html 单独打开。
2. 双击桌面上的“课表转日历工具”快捷方式。如果桌面上没有快捷方式，就双击项目文件夹里的“启动课表转换工具.cmd”。
3. 黑色窗口要保持打开，不要关掉。
4. 浏览器会自动打开 http://127.0.0.1:8787 。如果没有自动打开，就手动复制这个地址到浏览器。
5. 把学校导出的“学期总课程表”PDF 拖到网页中。
6. 仔细核对课程名称、星期、节次、周次、地点和老师。
7. 填写“第 1 周周一”的日期。这个日期必须是真实的周一，程序不会从 PDF 猜日期。
8. 点击“生成 ICS 文件”，保存下载的 .ics 文件。
9. 手机导入：
   - iPhone/iPad：在“文件”或 Safari 中打开 .ics，选择“添加全部”。
   - Android/Google 日历：在电脑打开 Google 日历网页，进入“设置 → 导入和导出”。
   - Outlook：日历 → 添加日历 → 从文件上传。

如果看到 “Failed to fetch”：

- 先关闭网页；
- 确认黑色窗口还在运行；
- 再双击“启动课表转换工具.cmd”；
- 等浏览器打开 127.0.0.1:8787 后再上传；
- 不要直接双击 static\index.html。直接打开它会找不到后端服务。

二、让别人点击网址使用

可以。这个项目已经包含 Dockerfile 和 Render 配置，可以部署成公开网址。你需要先准备一个 GitHub 账号和一个 Render 账号；部署成功后，平台会给你一个网址。

1. 注册 GitHub，把本项目文件上传到一个仓库。不要上传个人 PDF、个人 ICS 或包含学号的文件。
2. 注册 Render，选择 New → Web Service → Connect a repository，选刚才的仓库。
3. Runtime 选择 Docker，健康检查地址填 /healthz，然后点击 Deploy。
4. 部署完成后，Render 会给出一个 https://……onrender.com 网址，把这个网址发给别人即可。

注意：Render 免费方案长时间没人访问会休眠，第一次打开可能要等待几十秒；要一直快速响应需要付费方案。公开网址上的任何人都可以上传 PDF，请不要上传不应公开的敏感文件。
上传 GitHub 前，请确认仓库里没有“资料”文件夹中的个人 PDF 和 ICS；项目已配置为忽略这两类文件，但仍建议上传前人工检查一次。

三、重要提醒

- PDF 只是课程数据，上传后务必核对预览表。
- 课表日期由“第 1 周周一”决定，填错会导致整学期日期偏移。
- 课程节次时间来自项目根目录的 period_times.json，如学校时间不同请先修改它再重启服务。
